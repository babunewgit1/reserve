@mahmudulhasan126

Yes, we need to send all 6 parameters. The from_date and to_date should define the time period for fetching deals. For example, if we specify 24 hours, the range should be from the current date and time to the next 24 hours.

The items_from and items_until parameters are for pagination, allowing us to fetch deals in chunks.

The radius_miles value should be sent according to the Figma design. For the address parameter, we should send the search text until we have the airport ID for that location. If you can pass the airport ID from the frontend, I can replace the text with the airport ID. However, how will you identify the airport ID for a specific search text?

FYI, I’ve already added a backend filter that searches for the airport ID based on the text you send and fetches the results using that airport ID.
