# Mega Menu: Desktop vs Mobile — Mismatch Report

---

## Summary

Desktop এবং Mobile মেগা মেনুর মধ্যে মোট **13টি mismatch** পাওয়া গেছে। বেশিরভাগই capitalization/typo সংক্রান্ত, কিন্তু একটি section header সম্পূর্ণ ভিন্ন নাম ব্যবহার করেছে।

---

## 1. Fly Menu ✅ No Mismatches

Desktop ও Mobile-এ সব items, links, এবং labels হুবহু একই।

---

## 2. Programs Menu ⚠️ 3 Mismatches

| # | Location | Desktop | Mobile | Issue |
|---|----------|---------|--------|-------|
| 1 | Jet Cards → 5th item text | `Pay-as-you-fly Card` | `Pay-As-You-Fly Card` | Capitalization ভিন্ন |
| 2 | Premium Programs → 2nd item text | `Enterprise Jet card` (lowercase 'c') | `Enterprise Jet Card` (uppercase 'C') | Capitalization ভিন্ন |
| 3 | CTA button text | `Compare Programs` | `Compare PRograms` | **Typo** — Mobile-তে 'PR' uppercase |

## 3. Enterprise Menu ⚠️ 1 Mismatch

| # | Location | Desktop | Mobile | Issue |
|---|----------|---------|--------|-------|
| 1 | 2nd column header | `Institutions` | `INDUSTRIES` | **সম্পূর্ণ ভিন্ন নাম** — এটা শুধু case পরিবর্তন না, শব্দই আলাদা |

> [!WARNING]
> এটি সবচেয়ে গুরুত্বপূর্ণ mismatch। Desktop-এ "Institutions" আর Mobile-এ "INDUSTRIES" — দুটো সম্পূর্ণ আলাদা শব্দ ব্যবহার করা হয়েছে।
